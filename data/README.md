# Datos del mapa

El programa guarda aquí `mapa.txt` y su respaldo `mapa.txt.bak`.
`mapa-inicial.txt` contiene la copia inicial del circuito aproximado y se incluye en GitHub. Al ejecutar `iniciar.ps1` por primera vez, se copia a `mapa.txt` si ese archivo todavía no existe.
El mapa de trabajo, los respaldos y archivos temporales quedan excluidos de Git. El arranque nunca reemplaza un mapa existente. Conserva esta carpeta cuando copies tu trabajo actualizado a otra computadora.
El archivo `.lock` puede permanecer al cerrar; el bloqueo real pertenece al proceso del servidor.
Consulta el README principal para las operaciones de guardado y recuperación.
